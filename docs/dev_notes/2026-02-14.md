## **Critical Problems Solved**

- **Tight coupling to Streamlit for DB**: App and services depended on Streamlit for DB connections, blocking reuse by FastAPI and scripts. Refactored to a single framework-agnostic connection factory in `services/db.py`; later added pooling and safe return (rollback + discard closed).
- **Walkability query scalability**: Single geocode-and-query path and degree-based radius made “X miles” inconsistent and discouraged index use. Introduced coordinate-based query with geography and bbox prefilter for index-friendly behavior.
- **No API surface for frontends**: Streamlit-only UI blocked embedding and alternate clients. Added FastAPI app with geocoding, walkability, and NWI summary-by-query endpoints plus consistent error responses and CORS; later deprecated Streamlit entirely (React + FastAPI only).
- **Per-request DB and geocoding cost**: Every request opened a new DB connection and hit Nominatim. Added connection pooling (`ThreadedConnectionPool`), geocoding `@lru_cache`, and correct pool return (rollback before putconn, putconn(close=True) for broken connections).
- **Duplicate validation and doc drift**: Default/limit drift across frontend/backend and stale docs. Centralized query normalization and radius constants; aligned default radius behavior; updated README, tests/README, frontend/README.

## **Technical Implementation Details**

### **DB connection (db.py)**

- `get_db_connection()`: builds `psycopg2.connect()` from `PG*` or from `DATABASE_URL` if set.
- Pool: `get_pool()`, `get_pooled_connection()`, `return_connection()` (rollback then putconn; putconn(close=True) for broken connections), `close_pool()` in lifespan.
- No Streamlit imports; `validate_pg_env()` / `get_pg_env()` shared by scripts and services.

### **Walkability query (walkability.py)**

- `query_walkability_by_coords(lon, lat, radius_miles, conn=None)` uses PostGIS geography and a bbox prefilter (e.g. `ST_Intersects(geometry, ST_MakeEnvelope(...))`) before `ST_DWithin` to avoid full scans.

### **API error envelope (api/schemas.py, api/main.py)**

- Shared `ErrorResponse` (e.g. `code`, `message`, `detail`); HTTP and validation exceptions mapped to same shape; `_raise_api_error` typed as `NoReturn`.
