## **Technical Implementation Details**

### **Mobile CSS split**

- Mobile-specific rules live in `mobile.css` and load after `App.css` so overrides stay predictable without duplicating the entire desktop stylesheet.

### **Leaflet and tests**

- When production code uses chainable Leaflet APIs, test doubles must implement the same contract (return values and event helpers) or unit tests fail while runtime works — captured in `docs/dev_notes/lessons.md` (2026-04-17).

### **E2E API mocking**

- Mobile tests mock `/health` and `/nwi/summary` to avoid network flakiness; compare flow mock was aligned with `NwiSummaryResponse` before merge.

### **WAS join semantics**

- NWI ↔ WAS alignment is keyed on `geoid20` (12 characters, zero-padded). The inspection script’s join probe intentionally measures overlap against the full distinct GEOID set from the shapefile, not a geographic head slice.
