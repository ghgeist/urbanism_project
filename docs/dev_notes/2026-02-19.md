## **Technical Implementation Details**

### **Geocoding Fallback Flow**
```python
# services/walkability.py (simplified)
def get_location(query: str):
    result = _geocode_via_nominatim(query)
    if result is None:
        result = _geocode_via_census(query)
    return result
```

### **Choropleth Color Scale**
NWI scores (0–20) are mapped to a sequential color ramp in `MapView.tsx`. Block groups with `null` or missing scores receive a neutral gray fill and reduced opacity to visually distinguish them from scored areas.

### **Error Handling & Case Preservation**
The `service_unavailable` error code distinguishes service outages (e.g., Census API downtime) from other error types like `not_found` or `invalid_input`. Geocoding normalization now preserves original capitalization when converting UK street suffixes to US format (e.g., "Main St" stays "Main St", not "Main Street"), maintaining user input fidelity while still handling spelling variations.
