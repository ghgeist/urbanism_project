## **Technical Implementation Details**

### **Geocoding Fallback Flow**
```python
# services/walkability.py (simplified)
def get_location(query: str):
    result = _geocode_via_nominatim(query)
    if result is None:
        result = _geocode_via_census(query)
    return result
```

### **Choropleth Color Scale**
NWI scores (0–20) are mapped to a sequential color ramp in `MapView.tsx`. Block groups with `null` or missing scores receive a neutral gray fill and reduced opacity to visually distinguish them from scored areas.
